# Changelog

## [1.0.2] - 2026-09-17

### Fixed
- The flourish at the foot of the file explorer (the "Declassified" stamp) sat on top of the list and could cover file names. It now sits in the flow at the end of the list, below the last file, and scrolls with it. The reserved space at the bottom of the explorer is gone.
- Long callout titles no longer run under the "Urgent" tag.

## [1.0.1] - 2026-09-12

### Fixed
- Removed `text-decoration-color` (flagged by the theme linter); strikethroughs use the text colour.

## [1.0.0] - 2026-09-12

### Added
- First release. Every note is a case file: manila-folder chrome, typewriter type (Special Elite, Courier Prime, Oswald — embedded), red margin rule, CONFIDENTIAL and DECLASSIFIED stamps, callouts labelled EXHIBIT / MEMO / NOTICE / QUERY / STATEMENT / CLOSED with an URGENT sticker on warnings, dashed transcript code blocks, stamped tags, red-filled checkboxes.
- Highlights render as redaction bars and reveal on hover (and on the line you're editing).
- Day mode (paper on a desk) and night mode (microfilm).
